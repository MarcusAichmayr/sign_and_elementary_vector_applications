# Applications of Sign and Elementary Vectors

In this repository,
we present [applications, illustrative examples, and runtime experiments](https://marcusaichmayr.github.io/sign_and_elementary_vector_applications/) of the SageMath packages:

* [elementary_vectors](https://github.com/MarcusAichmayr/elementary_vectors)
* [certlin](https://github.com/MarcusAichmayr/certlin)
* [sign_vectors](https://github.com/MarcusAichmayr/sign_vectors)
* [sign_crn](https://github.com/MarcusAichmayr/sign_crn)
